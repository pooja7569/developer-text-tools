# Privacy Policy for DevToolBox

DevToolBox does not collect, store, sell, or share personal information, browsing history, or user analytics.

- **Local Processing:** JSON formatting and highlighted webpage text capture run entirely inside your local browser popup. No webpage data is transmitted to external servers during these actions.
- **Log-to-CSV Conversion:** When you explicitly click "Download CSV," the text inside the input box is sent over encrypted HTTPS to `https://developer-log-tools-pooja.onrender.com` solely to parse the log text and return a `.csv` file. Submitted log text is processed in memory and is not permanently stored or logged.
- **Contact:** For privacy questions or support, please open an issue on our GitHub repository.
